# Extraction Squad — Website v1

A responsive, static website for the Extraction Squad Ghosts of Tabor creator collective.

## Preview
Open `index.html` in any modern browser. The site has no build step or dependencies. Fonts load from Google Fonts when online; local fallbacks are provided.

## Publish for free on GitHub Pages
1. Create a public repository on GitHub, e.g. `extraction-squad`.
2. Upload **the contents of this folder** (index.html, styles.css, script.js, assets) to the repository root.
3. Open Settings > Pages > Build and deployment. Select **Deploy from a branch**, `main`, and `/ (root)`.
4. Wait for GitHub to provide your public URL, typically `https://YOUR-USERNAME.github.io/extraction-squad/`.

## Before launch
- Replace the YouTube **search results** links in index.html with each creator's confirmed channel URL. Search links are placeholders, not official profiles.
- Add the squad's confirmed Discord invite and social accounts.
- Replace the placeholder Missions section with featured video embeds or links.
- Review and approve the operator bios with the members.
- Adjust the fan/community disclaimer if appropriate.

## Files
- `index.html` — all site sections and text
- `styles.css` — layout, responsive styling and visual design
- `script.js` — operator dossiers and mobile navigation
- `assets/*.webp` — squad artwork

No analytics, trackers, or user data collection are included.
